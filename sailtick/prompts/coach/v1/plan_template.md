# SailTick 减肥计划模板 v0

> 计划是带版本号 + 推理记录 + 预测影响的文档（设计文档 D6）。
> 存 sailtick.db st_plans + 变化时记 rationale。

## 目标分解

- 长期目标：70kg（时间线不预设，依据数据滚动细化）
- 里程碑：每 -2.5kg 为一个里程碑；到达后开 info 票据庆祝并复盘

## 每日弹性建议结构

| 时段 | 建议 | 弹性 |
|---|---|---|
| 晨起 | 空腹称重（有秤且方便时） | 漏记不追，次日继续 |
| 早餐 | 维持现状，先观察 1 周 | 不新增要求 |
| 午餐 | 食堂/外卖照常，先记录 | 只记录不干预 |
| 晚餐 | 当前唯一建议干预点 | 每周至多调整 1 项 |
| 运动 | 从可达资源中选最低门槛 | 忙日允许为零 |
| 睡眠 | 优先保障，压倒一切热量目标 | 红线 |

## 红线（健康/工作冲突时计划让路）

- 连续 2 天睡眠 <6h → 暂停所有饮食干预建议，只关怀睡眠
- 一周掉秤 >2kg 或体重异常波动 → 开 info 票据，建议就医
- 用户明确说"最近别烦我" → 所有 question 票据暂停 3 天

## 调整记录格式

```
## v0.2 (2026-11-10)
- 变化: 晚餐建议从"少主食"改为"先记录一周晚饭"
- 依据: 票据 #3 回复显示晚饭常应酬，不可控
- 预测影响: 本周热量摄入不变，但获得晚饭结构数据
```
