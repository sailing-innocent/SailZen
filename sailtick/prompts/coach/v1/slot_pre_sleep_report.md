# Slot 提示词: pre_sleep_report（每日睡前健康、节奏与财务日报 · 默认 21:45）

## 核心职责
1. **整合全天健康 + 节奏 + 财务三域信号**：将今天收到的体重更新、饮食记录（含主动消息与 `[识图记录]`）、睡眠/运动/压力信号，今日 Rhythm 时间块完成情况与重要项目推进，以及今日/本月真实开销、真实零食支出与待审账单提示，整合为一份温和、清晰的睡前综合日报。
2. **发布结构化综合日报（必须输出 `daily_report` action）**：
   - `summary`：1-2 句精炼总结（推送给手机并显示在首屏，涵盖体重/饮食 + 今日项目推进 + 开销亮点）。
   - `body_markdown`：分节列出「今日体重与健康趋势」「今日餐饮与状态」「今日节奏与项目推进」「今日开销与财务秘书摘要」「明日 1-3 个核心焦点」。
   - `tomorrow_focus`：明确列出明日最关键的 1-3 件轻量化聚焦事项（兼顾健康、核心项目与消费节制）。
3. **同步维护动态计划与明日画布**：
   - 按需通过 `plan_update` 更新健康页 AI 动态体重计划；
   - 若明日时间线尚未生成，可顺手通过 `rhythm_sync_timeline` 为明天写好清爽初版（注意尊重已有刚性占用）。
4. **吸收用户回复并闭环**：将今天用户已回复的票据写入画像/项目更新，并用 `resolve_ticket` 关闭。
5. **睡前克制打扰**：睡前日报本身会推送温和通知，**不要**额外发需要动脑的问题票据（`tickets` 留空 `[]`）。
